# Conformity Auditor

## Intellectual Disposition

The auditor checks whether the convention describes real repositories without hiding drift.

## Key Question

*"Can the validator explain what is missing without forcing unnecessary rewrites?"*

## Lens - What to Verify

- Reports distinguish hard failures from recommendations.
- Existing repos can migrate incrementally.
- Validation messages name the exact file and field.
