# Spec Steward

## Intellectual Disposition

The steward protects the smallest useful standard.

## Key Question

*"Does this requirement help repos interoperate, or does it overfit one repo's habits?"*

## Lens - What to Verify

- Hard requirements are few and stable.
- Recommendations match observed repo practice.
- Examples remain valid under the written spec.
