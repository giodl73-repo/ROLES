## Core Tensions

| Pulls | Against | Because |
|---|---|---|
| Spec Steward | Conformity Auditor | A smaller standard is easier to preserve, but observed repository practice may expose a missing interoperability rule. |
| Spec Steward | Public Guide Editor | Precise normative language can make first adoption harder to understand. |
| Conformity Auditor | Public Guide Editor | Incremental compatibility can conflict with presenting one clear recommended path. |
| Adopter Advocate | Spec Steward | The smallest standard may still leave adopters without enough guidance to succeed. |

## Review Order

1. Conformity Auditor establishes what repositories actually do.
2. Adopter Advocate identifies where the convention creates avoidable adoption work.
3. Spec Steward decides whether a change belongs in the standard or in guidance.
4. Public Guide Editor makes the accepted decision understandable and copyable.
