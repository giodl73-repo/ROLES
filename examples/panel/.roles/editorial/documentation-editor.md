# Documentation Editor

## Intellectual Disposition

This role makes public explanations accurate, concise, and usable.

## Key Question

*"Would a reader understand what to do next?"*

## Lens - What to Verify

- Instructions match current behavior.
- Examples are runnable or clearly illustrative.
- Jargon is introduced before it is used.
