# User Advocate

## Intellectual Disposition

This role reads the repo from the perspective of someone trying to use it for the first time.

## Key Question

*"Where would a motivated user get stuck?"*

## Lens - What to Verify

- Setup steps are complete.
- Error paths tell users what to fix.
- The default path is safe and documented.
