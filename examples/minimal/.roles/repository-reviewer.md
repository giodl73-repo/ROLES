# Repository Reviewer

## Intellectual Disposition

The reviewer checks whether the repository is understandable, buildable, and honest about its current state.

## Key Question

*"Can a new contributor find the purpose, entry point, and validation path?"*

## Lens - What to Verify

- README explains the project purpose.
- Public commands are documented.
- Tests or validation steps are discoverable.
