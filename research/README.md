# ROLES Research

ROLES uses repository evidence to improve the `.roles` convention without
turning one portfolio's habits into universal requirements.

## Studies

- [Role Panels in Practice](portfolio-role-quality-study.md) reports a
  77-repository structural audit covering 1,120 committed role files.
- [Productive Tension in Repository Review Panels](productive-tension-study.md)
  examines how panels preserve disagreement and convert it into review
  decisions.

The source dataset is generated in
[`giodl73-repo/TRACKER`](https://github.com/giodl73-repo/TRACKER) by
`scripts/refresh-portfolio-role-quality.ps1`. The generated
`portfolio-role-quality.json` file is the machine-readable result, and
`PORTFOLIO_ROLE_QUALITY.md` is the ranked human-readable report.

These studies describe one related portfolio. They are evidence for improving
ROLES, not proof that the same distributions hold across independent
organizations or open-source ecosystems.
